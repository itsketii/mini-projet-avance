    MINI-PROJEt (avancé) : SITE PERSONNEL AVEC BOOTSTRAP

Dans le cadre de la formation IIT Learn 25-26, ce dépot contient le mini-projet (avancé) réalisé lors du troisième jour de formation, axées sur la création d'un site personnel avec Bootstrap.

---

### Objectifs validés

* Intégrer Bootstrap dans un projet (via CDN) et comprendre son système de grille
* Utiliser plusieurs composants Bootstrap (navbar, cards, carousel ou modal, formulaire)
* Continuer à écrire du CSS personnel pour personnaliser le rendu par défaut de Bootstrap
* Structurer un site de plusieurs sections, avec une navigation qui fonctionne sur mobile comme sur desktop
